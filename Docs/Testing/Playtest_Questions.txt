ขวัญเอ้ย ขวัญมา - คำถามสำหรับ Playtest
==================================================

หลักการตั้งคำถาม
- ทุกข้อให้ผู้ทดสอบบอก ตรงไหน / ทำอะไรอยู่ / เกิดอะไรขึ้น ไม่ใช่ตอบแค่ว่า "ดี" หรือ "ไม่ดี"
- ข้อที่ให้คะแนน 1-5 ต้องมีช่อง "ถ้าได้ <=3 เพราะอะไร" ต่อท้ายเสมอ
- ขอให้ผู้ทดสอบจดชื่อการ์ดเป็น s_xxxx หรือชื่อไทย และระบุฉาก (Map / Combat / Event / Shop / Reward / เมรุ)


1. บั๊กและความเสถียร (แก้ได้ทันที)
--------------------------------------------------
1. มีจุดไหนที่เกมค้าง หน้าจอดำ หรือกดแล้วไม่ไปต่อไหม ตอนนั้นอยู่ฉากไหนและเพิ่งกดอะไร
2. ข้ามฉากแล้วค่าต่อไปนี้ผิดไหม: ขวัญ ธูป เด็ค เครื่องรางติดตัว
   (เช่น ซื้อของแล้วเงินไม่ลด หรือออกจากการต่อสู้แล้วเลือดเด้งกลับ)
3. ปิดเกมแล้วกด Continue ได้กลับมาที่จุดเดิมไหม ข้อมูลอะไรหายไปบ้าง
4. มีปุ่มไหนกดได้ทั้งที่ไม่ควรกดได้ไหม (เช่น เล่นการ์ดตอนเป็นตาศัตรู หรือกดซื้อตอนเงินไม่พอ)
5. กด Esc แล้วหยุดเกมได้ทุกฉากไหม พอกลับมาเล่นต่อ มีอะไรเพี้ยนไหม


2. Combat
--------------------------------------------------
6. อ่านการ์ดใบไหนแล้วไม่เข้าใจ หรือเล่นแล้วผลไม่ตรงกับข้อความบนการ์ด (บอกชื่อการ์ด)
7. รู้ไหมว่าตอนนี้กุศลกับมลทินเหลือเท่าไร และถ้ามลทินเต็มจะเกิดอะไรขึ้น
8. รู้ไหมว่าศัตรูจะทำอะไรในเทิร์นถัดไป ถ้าไม่รู้ อยากเห็นข้อมูลอะไร
9. ตอนเกิด Curse Backfire รู้ไหมว่าเกิดขึ้นแล้วและเกิดเพราะอะไร
10. มีช่วงไหนที่ไม่รู้ว่าตอนนี้เป็นตาใคร หรือต้องกดอะไรต่อ
11. บริวารที่ลงสนามแล้ว มองออกไหมว่าตัวไหนเป็นของเรา ตัวไหนเป็นของศัตรู


3. Map, Event, Shop, Reward, เมรุ
--------------------------------------------------
12. ดูแผนที่แล้วรู้ไหมว่าแต่ละจุดคืออะไร (เมรุ ศาล หมอกดำ กองของเซ่น) ไอคอนไหนสับสน
13. ในหมอกดำ มีตัวเลือกไหนที่เลือกไปแล้วผลออกมาไม่ตรงกับที่คาดไว้ (บอกชื่อ event)
14. ในศาล อ่านราคาและผลของสินค้าชัดไหม มีของที่ไม่รู้ว่าซื้อไปแล้วได้อะไร
15. ตอนเลือกการ์ดรางวัล ตัดสินใจเลือกได้ไหม หรือข้อมูลไม่พอให้เลือก
16. ในเมรุ เข้าใจไหมว่าเผาการ์ดกับอัปเกรดการ์ดต่างกันอย่างไร


4. UI และการอ่าน
--------------------------------------------------
17. มีข้อความไหนที่อ่านยาก เช่น ฟอนต์เล็กไป สีกลืนกับพื้น ตัวอักษรไทยแตก หรือสระลอย
    (ถ้าได้ให้แคปจอมาด้วย)
18. มีปุ่มหรือข้อความไหนที่ล้นหรือถูกบังเมื่อเปลี่ยนความละเอียดหน้าจอ
19. หน้า Settings ใช้แล้วได้ผลจริงไหม เช่น ปรับเสียง หรือสลับ fullscreen/windowed


5. เสียงและภาพ
--------------------------------------------------
20. มีเสียงไหนดังหรือเบาผิดปกติ หรือมีจังหวะที่ควรมีเสียงแต่เงียบไป
21. เพลงตัดตอนข้ามฉากแบบกระตุกไหม
22. มีการ์ดใบไหนที่ภาพหาย หรือยังเป็นภาพ placeholder


6. Balance (ข้อมูลส่งให้ทีมตัดสินใจ dev ไม่แก้เอง)
--------------------------------------------------
23. ตายที่ด่านไหน ศัตรูตัวไหน เหลือขวัญเท่าไรตอนเข้าสู้ครั้งนั้น
24. มีการ์ดใบไหนที่แรงจนเลือกทุกครั้ง หรืออ่อนจนไม่เคยหยิบเลย
25. ธูปพอใช้ไหม พอถึงศาลแล้วซื้ออะไรได้บ้าง
26. เล่นจบหนึ่งรอบใช้เวลากี่นาที ช่วงไหนรู้สึกยืดหรือน่าเบื่อ


7. ปิดท้าย
--------------------------------------------------
27. ถ้าแก้ได้แค่หนึ่งอย่างก่อนวันนำเสนอ อยากให้แก้อะไร
28. มีช่วงไหนที่ต้องถามคนข้าง ๆ ว่า "ต้องทำอะไรต่อ"
    (ข้อนี้ชี้จุดที่ tutorial หรือ UI ยังสื่อไม่ชัด)
